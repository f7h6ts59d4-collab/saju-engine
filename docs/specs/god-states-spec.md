# god-states-spec: 십성 기운(투출·통근) 모듈 명세 (v1)

리프 모듈. correctPillars 오케스트레이터에 `godStates` 필드로 통합.
기존 출력에 필드 추가만 하며, 기존 소비자를 깨지 않는다.
strength와 독립(역할 분리 — strength는 일간의 뿌리와 강약 점수, 이 모듈은 다섯
십성 그룹의 세력)이되, 통근 판정 기준은 strength-spec 학파 스위치 표를 공유한다.

## 목적

해석층이 "재성이 천간에 떴는가", "관성의 뿌리가 어디인가"를 지장간 표에서
매번 스캔하지 않고 엔진 값으로 받게 한다. 존재 여부의 기계적 조회만 하고,
생극 흐름·발현 해석은 해석층 몫 — 역할 분리.

## 판정 규칙

십성 그룹 5개(비겁·식상·재성·관성·인성) 각각에 대해:

- **투출(exposed)**: 일간을 제외한 천간 3자리(연간·월간·시간)에 해당 그룹의
  십성이 있으면 그 자리·글자·개별 십성명을 기록.
- **뿌리(rooted)**: 4지지의 지장간(정기·중기·여기 전부)에 해당 그룹 오행의
  글자가 있으면 지지·궁위(연지/월지/일지/시지)·층(정기/중기/여기)·글자·
  개별 십성명·조습(earth)을 기록. 시간 모름이면 시주 제외.
  - 통근 기준은 strength-spec 학파 스위치 표를 공유한다
    (조토생금 인정 — 조습은 뿌리 인정에 영향 없음, earth 플래그로만 표시).
  - earth: 미·술=조토, 진·축=습토, 그 외 null. 표시 플래그일 뿐
    뿌리 인정·상태 판정에 영향을 주지 않는다.
- **상태(state)**: 4단 분류.
  - 투출유근 — 천간에 있고 지지에 뿌리도 있음 (가장 강함)
  - 투출무근 — 천간에 떠 있으나 뿌리 없음 (허부)
  - 잠복 — 천간에 없고 지지(정기 포함)에만 있음
  - 무 — 어디에도 없음
- **기록 순서(결정적)**: exposed는 연간→월간→시간, rooted는 연지→월지→일지→시지,
  같은 지지 안에서는 여기→중기→정기(지장간 배열 순서).

층별 가중이나 점수화는 하지 않는다 (강약 점수는 strength 모듈 소관).
합충에 의한 상태 반영도 하지 않는다 (해석층 몫 — relations를 함께 읽으면 된다).

## 출력 형태

```ts
godStates: {
  비겁: GodState; 식상: GodState; 재성: GodState; 관성: GodState; 인성: GodState;
}

type GodState = {
  exposed: Array<{ position: '연간'|'월간'|'시간'; stem: string; god: string }>;
  rooted: Array<{
    branch: string;
    pillar: '연지'|'월지'|'일지'|'시지';   // 궁위 — 같은 지지 중복 명식에서 필수
    layer: '정기'|'중기'|'여기';
    stem: string;
    god: string;
    earth: '조토'|'습토'|null;            // 미·술=조토, 진·축=습토, 그 외 null
  }>;
  state: '투출유근'|'투출무근'|'잠복'|'무';
}
```

## 검증 케이스

### 카논 1 (1992-07-23 04:30 대구 → 임신 정미 경자 무인, 일간 경금)

| 그룹 | exposed | rooted | state |
|---|---|---|---|
| 비겁 | 없음 | 신(연지, 정기 경=비견) | 잠복 |
| 식상 | 임(연간, 식신) | 신(연지, 중기 임=식신) · 자(일지, 여기 임=식신) · 자(일지, 정기 계=상관) | 투출유근 |
| 재성 | 없음 | 미(월지, 중기 을=정재, 조토) · 인(시지, 정기 갑=편재) | 잠복 |
| 관성 | 정(월간, 정관) | 미(월지, 여기 정=정관, 조토) · 인(시지, 중기 병=편관) | 투출유근 |
| 인성 | 무(시간, 편인) | 신(연지, 여기 무=편인) · 미(월지, 정기 기=정인, 조토) · 인(시지, 여기 무=편인) | 투출유근 |

이 표가 지난 분석들에서 손으로 도출해온 판단("재성 천간 불투", "편관은
지장간 잠복", "정관 투출 + 월지 뿌리")과 일치하는지가 통과 기준.

### 카논 2 — 무·잠복 케이스 (1990-02-13 14:30 대구 → 경오 무인 기유 신미, 일간 기토)

재성 완전 부재(무) + 잠복 상태 검증을 겸한다. 탐색 불필요 — 실제 명식으로 고정.

| 그룹 | exposed | rooted | state |
|---|---|---|---|
| 비겁 | 무(월간, 겁재) | 오(연지, 중기 기=비견) · 인(월지, 여기 무=겁재) · 미(시지, 정기 기=비견, 조토) | 투출유근 |
| 식상 | 경(연간, 상관) · 신(시간, 식신) | 유(일지, 여기 경=상관) · 유(일지, 정기 신=식신) | 투출유근 |
| 재성 | 없음 | 없음 | 무 |
| 관성 | 없음 | 인(월지, 정기 갑=정관) · 미(시지, 중기 을=편관, 조토) | 잠복 |
| 인성 | 없음 | 오(연지, 여기 병=정인) · 오(연지, 정기 정=편인) · 인(월지, 중기 병=정인) · 미(시지, 여기 정=편인, 조토) | 잠복 |

### 투출무근 케이스 (탐색으로 고정)

탐색 결과 고정 (대구 Asia/Seoul, 1950~2005 탐색 첫 매치):
- 1950-01-01 12:30 → 기축 병자 병신 갑오, 일간 병화.
  **인성(목) = 투출무근**: 갑(시간, 편인) 투출, 지지 축·자·신·오 지장간
  어디에도 목이 없어 뿌리 0 (허부).
- 이 명식은 왕지 2엔트리 검증을 겸한다: 비겁 rooted가 오(시지) 한 지지에서
  여기 병=비견·정기 정=겁재 2엔트리, strength.factors.roots는 오(시지) 1엔트리.

### 교차 불변식 (strength와 같은 사실의 이중 계산)

임의 명식에서 `godStates.비겁.rooted`의 (pillar, branch) 중복 제거 집합
== `strength.factors.roots`의 (pillar, branch) 집합.
엔트리 수 비교 금지: 자(子)·오(午)처럼 같은 오행 지장간이 2개인 지지는
godStates에 2엔트리, strength에 1엔트리로 기록되는 게 정상이다.

### 기타

- 시간 모름: 시주 제외 확인 — exposed에 시간 없음, rooted에 시지 없음.
  카논 1을 시간 없이 넣으면 인성은 투출(시간 무)이 빠져 잠복이 된다.
- 회귀: 기존 필드 전부 불변 (strength.factors.roots의 pillar 가산 제외 —
  strength-spec v1.1 개정 참조).

## 명시적 비목표 (v1)

- 점수화·강도 순위 없음 (상태 4단 분류까지만)
- 합충 상태 반영 없음
- 월령 사령 반영 없음
- 조습에 따른 뿌리 차감 없음 — earth는 표시 플래그만 (조후 분리반영 노선,
  strength-spec과 동일)
